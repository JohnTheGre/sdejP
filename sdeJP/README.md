## Design Patterns

### Creational Patterns
1. **Factory Pattern**: Used to create objects without specifying the exact class.
2. **Singleton Pattern**: Ensures only one instance of a class is created.

### Structural Patterns
1. **Decorator Pattern**: Adds behavior to objects dynamically.
2. **Adapter Pattern**: Allows incompatible interfaces to work together.

### Behavioral Patterns
1. **Observer Pattern**: Notifies multiple objects about state changes.
2. **Strategy Pattern**: Encapsulates interchangeable algorithms.
